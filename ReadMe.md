# Small Calculator

A small calculator application built with **JavaFX** as a voluntary learning project.

I'm building it from scratch without Scene Builder to practise JavaFX layouts, component design, event handling, and general Java development.

## Current Status

**In development**

### Currently implemented

- JavaFX application structure
- Custom GUI components using `HBox`, `VBox`, and `GridPane`
- Reusable button creation through a small `GUIFactory`
- Dynamically generated calculator keypad
- Basic button event handling
- Expression input through the calculator display

### Planned

- [ ] Calculator operations
- [ ] Expression parsing and evaluation
- [ ] Clear/delete functionality
- [ ] Windows Calculator-style menu
- [ ] JavaFX CSS styling
- [ ] Menu animations
- [ ] More complete error handling

## Why I Built This

This isn't a university assignment. I'm building it voluntarily to get more comfortable with JavaFX and to practise building a project without following a predefined implementation.

The goal is to start with a simple GUI and gradually turn it into a fully functional calculator.
